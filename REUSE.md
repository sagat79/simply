## Generated Files

The following directories contain generated files that inherit their licensing from source files:

- `assets/` - Built assets generated from source files in `src/`
- `dist/` - Distribution files generated by build process

These generated files maintain the same licensing as their source files (GPL-3.0-or-later) but are not individually tagged to avoid duplication.

To verify REUSE compliance:

```bash

# Generate SPDX bill of materials
reuse spdx

# Check individual files
reuse lint-file <filename>
```
